# Vision dataset

Images used to train the crop-leaf classifier (`backend/models/vision/crop_disease.onnx`).
Licences, citations and per-source image counts are listed in [SOURCES.md](SOURCES.md).

## What's in git and what isn't

| Path | In git? | Content |
|---|---|---|
| `metadata/sources.csv` | yes | every downloaded archive: URL, SHA-256, download date, image style |
| `metadata/licenses.csv` | yes | licence, licence URL, citation and restrictions per source |
| `metadata/candidates.csv`, `duplicates.csv` | no (≈ 35 MB, regenerated by steps 2–4) | every image found + validity, quality, hashes; duplicate pairs |
| `metadata/duplicate_stats.json`, `removed_images.csv` | yes | duplicate / removal counts |
| `metadata/manifest.csv` | yes | every image used: label, source, licence, duplicate group, split |
| `metadata/classes.csv` | yes | class id → label, crop, condition, sources |
| `metadata/dataset_report.{json,md}` | yes | counts, balance, duplicates, train/test leakage |
| `SOURCES.md` | yes | generated licence + count summary |
| `raw/`, `processed/`, `train/`, `validation/`, `test/`, `field_test/` | **no** (≈ 2 GB) | archives, extracted images, split folders — rebuilt by the scripts |

## Rebuild from zero

```bash
backend/.venv/Scripts/python scripts/vision/build_dataset.py      # runs all steps below in order
```

| Step | Script | Output |
|---|---|---|
| 1 | `download_datasets.py` | `raw/<source>/` archives (SHA-256 checked) + extraction, `sources.csv`, `licenses.csv` |
| 2 | `validate_images.py` | `candidates.csv` (decodable, ≥ 64×64, quality score) |
| 3 | `remove_corrupt_images.py` | drops invalid images from the candidate list |
| 4 | `detect_duplicates.py` | exact (SHA-1) + near duplicates (difference hash ≤ 4 bits) grouped |
| 5 | `generate_manifest.py` | `manifest.csv`, `classes.csv` — only CC0 / CC BY 4.0 sources are accepted |
| 6 | `balance_classes.py` | caps large classes (1500 per class, 2000 `unsupported`, 600 unseen-crop test) |
| 7 | `create_splits.py` | group-aware 70/15/15 train/validation/test + `ood_test`; hard-linked folders |
| 8 | `dataset_report.py` | `dataset_report.{json,md}`, `SOURCES.md` |

## Rules

- Near-duplicate groups never span splits, and the report measures leakage (should be 0).
- `unsupported` = other plants and diseases the model doesn't cover, so unknown photos aren't forced into a class.
- `ood_test` = crops never seen in training (potato, pepper, strawberry, soybean, raspberry); used only to measure rejection.
- PlantVillage photos are lab photos; PlantDoc and the Mendeley sets are field photos. Evaluation reports each separately.
- To add a source: register it in `scripts/vision/common.py` (`SOURCES`, with licence + citation). A licence outside
  `ALLOWED_LICENSES` is refused. Never add images from search engines, Pinterest or unlicensed websites.
- Changing the data? Bump `DATASET_VERSION` in `common.py`; it is recorded in every model and every prediction.
